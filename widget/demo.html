Operations report (demo page for the chat widget)

How to use this page

This page stands in for the ASP.NET application. The chat button is at the bottom right.

Open it as http://127.0.0.1:8000/widget/demo.html?key=YOUR_API_KEY, with the API_KEY value from .env.

Development only: this page passes the API key to the browser. In the real application the key stays on the ASP.NET server (see docs/EMBEDDING.md), and the widget is added with one line: <script src="…/widget/ntpc-chat.js" data-endpoint="/chatbot"></script>
